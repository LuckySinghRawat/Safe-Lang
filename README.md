# 🛡️ Safe-Lang

**SafeLang** is a mini programming language and compiler built entirely in **Java**, designed to demonstrate core compiler design principles with a focus on **security and safety**. It features lexical analysis, syntax parsing, semantic checking, type enforcement, buffer overflow protection, and a built-in **dark-themed IDE** with syntax highlighting.

## ✨ Features

- **Custom Lexer** — Tokenizes Safe-Lang source code into categorized tokens (keywords, operators, literals, etc.)
- **Recursive Descent Parser** — Parses and executes code using a hand-written top-down parser
- **Variable Declaration & Assignment** — Declare variables with `Safelet` and reassign them freely
- **Arithmetic Expressions** — Full support for `+`, `-`, `*`, `/` with correct operator precedence and parentheses
- **Conditional Statements** — `Safeif` / `Safeelse` with comparison operators (`>`, `<`, `>=`, `<=`, `==`, `!=`)
- **While Loops** — `Safewhile` loops with full condition evaluation
- **Secure Input (`safeinput`)** — Type-enforced input with **buffer overflow protection**
  - `(int) safeinput(N)` — Integer input with max digit limit
  - `(str) safeinput(N)` — String input with max character limit
  - `(str) safeinput("default")` — String input with a default value
- **Type System** — Enforces `int` and `str` types; prevents type mismatch assignments
- **Division by Zero Protection** — Runtime error for division by zero
- **Comments** — Single-line comments with `//`
- **Built-in IDE (GUI)** — Dark-themed editor with:
  - Real-time syntax highlighting
  - Line numbers
  - Token table display
  - Output console
  - Run button with one-click execution

## 📋 Prerequisites

Before running Safe-Lang, ensure you have the following installed on your system:

| Requirement          | Minimum Version | Download Link                                                   |
| -------------------- | --------------- | --------------------------------------------------------------- |
| **Java JDK**         | 8 or higher     | [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) or [OpenJDK](https://openjdk.org/) |
| **Operating System** | Any             | Windows / macOS / Linux                                         |

### Verify Java Installation

Open a terminal or command prompt and run:

```bash
java -version
javac -version
```

You should see output similar to:

```
java version "17.0.x" ...
javac 17.0.x
```

> **Note:** No external libraries or build tools (Maven/Gradle) are required. SafeLang uses only the Java Standard Library, including **Swing** for the GUI.

## 🖥️ Running the IDE (GUI Mode)

Launch the built-in Safe-Lang IDE with the dark-themed editor:

```bash
java SafeLangGUI
```

### IDE Layout

| Panel             | Description                                      |
| ----------------- | ------------------------------------------------ |
| **Code Editor**   | Write Safe-Lang code with syntax highlighting    |
| **Tokens Table**  | Displays all tokens generated by the lexer       |
| **Output Console**| Shows execution results or error messages        |
| **Run Button**    | Click to tokenize, parse, and execute your code  |

### How to Use the IDE

1. Launch the IDE with `java SafeLangGUI`
2. Write your Safe-Lang code in the **Code Editor** panel
3. Click the **"Run Code"** button
4. View the generated tokens in the **Tokens Table**
5. See the output or errors in the **Output Console**

## 📖 Language Syntax & Keywords

### Keywords

| Keyword       | Description                                       |
| ------------- | ------------------------------------------------- |
| `Safelet`     | Declare a new variable                            |
| `Safeprint`   | Print a value or expression to the output         |
| `Safeif`      | Conditional if statement                          |
| `Safeelse`    | Else branch for conditional                       |
| `Safewhile`   | While loop                                        |
| `safeinput`   | Secure input with type enforcement                |
| `int`         | Integer type specifier (used with `safeinput`)    |
| `str`         | String type specifier (used with `safeinput`)     |

### Operators

| Operator | Description          |
| -------- | -------------------- |
| `+`      | Addition             |
| `-`      | Subtraction / Unary  |
| `*`      | Multiplication       |
| `/`      | Division             |
| `=`      | Assignment           |

### Comparison Operators

| Operator | Description              |
| -------- | ------------------------ |
| `>`      | Greater than             |
| `<`      | Less than                |
| `>=`     | Greater than or equal to |
| `<=`     | Less than or equal to    |

## 💡 Code Examples

### 1. Variable Declaration & Arithmetic

```
Safelet x = 10
Safelet y = 5
Safelet z = (x + y) * 2
Safeprint z
```

**Output:** `30`

### 2. Conditional Statements

```
Safelet score = 85

Safeif score >= 50 {
    Safeprint 1
} Safeelse {
    Safeprint 0
}
```

**Output:** `1`

### 3. While Loop

```
Safelet count = 5
Safewhile count > 0 {
    Safeprint count
    count = count - 1
}
```

**Output:**
```
5
4
3
2
1
```

### 4. Secure String Input with Buffer Overflow Protection

```
Safelet name = (str) safeinput(5)
name = "Safe"
Safeprint name
```

**Output:** `Input accepted: Safe` → `Safe`

```
// This will throw an error:
name = "TooLongString"
```

**Error:** `Error: characters are more than 5, buffer overflow protected`

### 5. Secure Integer Input with Digit Limit

```
Safelet age = (int) safeinput(3)
age = 25
Safeprint age
```

**Output:** `25`

```
// This will throw an error:
age = 10000
```

**Error:** `Error: invalid integer or size exceeded`

### 6. Comments

```
// This is a comment
Safelet x = 42   // inline comment
Safeprint x
```

**Output:** `42`

## 🏗️ Architecture

Safe-Lang follows a classic **compiler pipeline** architecture:

```
Source Code (.txt)
       │
       ▼
┌─────────────┐
│    Lexer     │  ← Tokenizes raw source code into tokens
│ (lexer.java) │
└──────┬──────┘
       │  List<token>
       ▼
┌──────────────┐
│    Parser     │  ← Parses tokens using recursive descent
│ (parser.java) │     and executes statements directly
└──────┬───────┘
       │
       ▼
   Output / Errors
```

### Component Details

| Component       | File               | Responsibility                                                   |
| --------------- | ------------------ | ---------------------------------------------------------------- |
| **Token**       | `token.java`       | Defines `tokentype` enum and `token` class with type categories  |
| **Lexer**       | `lexer.java`       | Scans source code character-by-character to produce tokens       |
| **Parser**      | `parser.java`      | Recursive descent parser that evaluates expressions and statements|
| **CLI Runner**  | `Main.java`        | Reads `f1.txt`, runs lexer + parser, prints tokens and output    |
| **GUI IDE**     | `SafeLangGUI.java` | Swing-based IDE with editor, token table, and output console     |

### Parser Grammar (Simplified)

```
program    → statement*
statement  → safelet_decl | safeprint | safeif | safewhile | assignment
safelet    → "Safelet" ID "=" (expr | typed_safeinput)
safeprint  → "Safeprint" expr
safeif     → "Safeif" condition block ("Safeelse" block)?
safewhile  → "Safewhile" condition block
assignment → ID "=" (expr | STRING)
block      → "{" statement* "}"
condition  → expr ((">" | "<" | ">=" | "<=" | "==" | "!=") expr)?
expr       → term (("+"|"-") term)*
term       → factor (("*"|"/") factor)*
factor     → NUMBER | ID | "(" expr ")" | "-" factor
```

## ⚠️ Error Handling

Safe-Lang provides clear, descriptive runtime error messages:

| Error                                | Cause                                             |
| ------------------------------------ | ------------------------------------------------- |
| `Undefined variable: x`             | Using a variable before declaring it with `Safelet`|
| `Division by zero error`            | Dividing by zero in an expression                 |
| `Type mismatch: cannot assign ...`  | Assigning wrong type to a typed variable          |
| `Buffer overflow protected`         | String exceeds the declared character limit        |
| `Invalid integer or size exceeded`  | Integer exceeds the declared digit limit           |
| `Unexpected token`                  | Syntax error in the code                          |
| `Invalid Character`                 | Unrecognized character in source code             |
